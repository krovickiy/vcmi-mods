# Особистий репозиторій модів VCMI

Один репозиторій на GitHub — і твої моди однаково з'являються на Mac, Windows і Android.

## Структура
- `mods/<id-мода>/` — вихідні файли кожного мода (`mod.json`, `content/…`, `screenshots/*.png`).
  Id — лише латиниця, цифри, дефіси. Папки на `_` (наприклад `_template`) не публікуються.
- `dist/` — готові zip-архіви (генеруються скриптом).
- `vcmi-repo.json` — індекс репозиторію для лаунчера (генерується).
- `vcmi-updates.json` — оголошення нової версії **самого лаунчера** (див. нижче).
- `publish.py` — пакування, автопідняття версії, публікація.

## Як додати або змінити мод
1. Скопіюй `mods/_template` → `mods/мій-мод`, заповни `mod.json`.
2. `python3 publish.py` — скрипт запакує мод, **сам підніме версію**, якщо вміст змінився, і відправить на GitHub.
3. На кожному пристрої лаунчер при запуску сам перевіряє репозиторії (налаштування «Автоматично перевіряти репозиторії» ввімкнене за замовчуванням) і показує «є оновлення»; тисни «Оновити».

## Одноразове підключення на кожному пристрої
Лаунчер → Налаштування → «Додатковий репозиторій» → увімкнути й вставити:
`https://raw.githubusercontent.com/krovickiy/vcmi-mods/main/vcmi-repo.json`

## Оновлення самого лаунчера (власна збірка з меню читів)
Моди — це дані, лаунчер — програма. Після змін коду збірку треба зробити для кожної платформи.
- **Сповіщення в лаунчері:** VCMI при старті читає `updateConfigUrl` і, якщо версія новіша, показує вікно
  «Доступне оновлення» з посиланням для своєї платформи. Для цього власна збірка має мати свій номер
  версії (напр. «VCMI 1.7.5 Cheats r2») і `updateConfigUrl` →
  `https://raw.githubusercontent.com/krovickiy/vcmi-mods/main/vcmi-updates.json`.
  При кожному релізі: змінити `version`, додати попередню в `history`, оновити `changeLog`.
- **Повністю автоматично на Android:** програма **Obtainium** (безкоштовна, з GitHub/F-Droid) стежить
  за GitHub Releases цього репозиторію і сама ставить новий APK.
- **Windows:** вікно-сповіщення з посиланням (VCMI не встановлює оновлення сам).
